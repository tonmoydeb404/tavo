# Tavo Desktop

Menu-bar audio control for macOS — switch input/output devices, mute the mic
globally, and route per-app audio. Built with [Tauri 2](https://tauri.app) +
React 19 + Tailwind v4.

## Develop

```sh
pnpm install
pnpm dev:desktop
```

## Verify

```sh
pnpm --filter @workspace/desktop typecheck
pnpm --filter @workspace/desktop lint
pnpm --filter @workspace/desktop build
cargo check --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml
```

## Branding

App name, identifier, version, updater endpoint, and Homebrew cask values are
single-sourced in `brand.json` at the repo root. After changing it, run
`pnpm sync-brand` (CI fails on drift via `pnpm sync-brand:check`). The
canonical logo is `public/logo.svg`; icon sets are regenerated by the same
script.

## Release signing

Updater artifacts are signed with a minisign keypair kept in the git-ignored
`.keys/` folder at the repo root. Generate it once with `pnpm keys:generate`
(it also writes the public key into `src-tauri/tauri.conf.json`); the command
prints the local-build and GitHub-secret commands. Never commit `.keys/`.
